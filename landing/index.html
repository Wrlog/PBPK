Physiologically based pharmacokinetic models

PBPK models describe where a drug goes and how it is eliminated, using the body's real organ volumes, blood flows and clearance pathways. That makes them the tool for questions like drug-drug interactions and dosing in children. Each model is an mrgsolve model and runs in your browser; nothing to install. The first load takes about half a minute while R starts up in the page.

How it works

Every model is an mrgsolve model file. Run locally with mrgsolve installed, the apps simulate through mrgsolve. In the browser, the small-molecule model is solved exactly by matrix exponential, and the other models are translated to R and solved with a stiff Rosenbrock solver. The test suite checks each browser engine against mrgsolve, and each model against its published results, before every deployment. Source: github.com/Wrlog/PBPK. For models that add pharmacodynamics and disease biology, see the QSP models.

For research and teaching only. Nothing here is validated for clinical use or should guide the treatment of a patient.
