# Physiologically based pharmacokinetic models

Four physiologically based pharmacokinetic (PBPK) models as
[mrgsolve](https://mrgsolve.org) models, each with an interactive Shiny app that
runs in the browser. PBPK models describe where a drug goes and how it is
eliminated, using real organ volumes, blood flows and clearance pathways. That
makes them the tool for drug-drug interactions and dosing in children. For models
that add pharmacodynamics and disease biology, see the
[QSP models](https://github.com/Wrlog/QSP).

**Apps:** <https://wrlog.github.io/PBPK/>. They run entirely in the browser
through WebAssembly, so there's nothing to install. The first load takes about
half a minute while R starts up in the page.

This is for research and teaching only. Nothing here is validated for clinical
use or should guide the treatment of a patient.

## The models

| App | Model | Source |
|---|---|---|
| [Small molecule](apps/small-molecule) | Whole-body, 12 perfusion-limited tissues; Rodgers & Rowland partition coefficients; hepatic, renal and gut-wall clearance; pediatric scaling. Midazolam, caffeine, metoprolol, thiopental, or your own compound | Built for this repository from the literature below |
| [DDI: CYP3A induction](apps/ddi-cyp3a) | Rifampicin (5-zone liver with OATP uptake, segregated-flow gut, UGT auto-induction) inducing hepatic and intestinal CYP3A; midazolam as the victim | Asaumi et al., *CPT:PSP* 2018;7:186 |
| [DDI: OATP + induction](apps/ddi-oatp) | Rifampicin inhibiting OATP uptake of glibenclamide while inducing CYP2C9/3A: a complex interaction that changes direction with timing | Asaumi et al., *CPT:PSP* 2018;7:186 |
| [Antibodies](apps/mab) | Second-generation minimal PBPK for IgG (plasma, tight and leaky interstitial fluid, lymph) with optional target-mediated disposition in the interstitial fluid. Trastuzumab and ten other antibodies | Cao, Balthasar & Jusko, *JPKPD* 2013;40:597; Cao & Jusko, *JPKPD* 2014;41:375 |

### Small-molecule whole-body PBPK

- **Distribution:** Kp values from the mechanistic Rodgers & Rowland equations
  (J Pharm Sci 2005;94:1259 and 2006;95:1238). Tissue composition is the data
  set distributed with Utsey et al. (Drug Metab Dispos 2020;48:903).
- **Clearance:** unbound hepatic intrinsic clearance (well-stirred liver), plus
  renal filtration.
- **Absorption:** first-order oral absorption with Fa and Fg.
- **Physiology:** organ volumes and flows rounded from ICRP 89 and Brown et al.
  (1997). Cardiac output scales with weight^0.75.
- **Children:** GFR maturation (Rhodin et al., Pediatr Nephrol 2009) and
  Hill-type enzyme ontogeny for CYP3A4, CYP1A2 and CYP2D6. The ontogeny parameters
  are rounded illustrations, and organ fractions don't change with age, so this is
  first-order pediatric scaling, not a full pediatric physiology.
- **Adult checks:** midazolam CL 25.6 L/h, Vss 1.45 L/kg, oral F 0.30; caffeine
  half-life 4 h in adults and about 58 h in neonates.

### Rifampicin DDI models

Both are transcribed from the model code in the Supplementary Text of Asaumi
et al. 2018. Parameter values come from its Supplementary Tables S1–S2 and the
optimised values in Table 1.

- **Midazolam:** carried over directly. Rifampicin's unbound concentrations in
  hepatocytes and enterocytes induce CYP3A and UGT through an enzyme-turnover
  model (Emax 4.57, EC50,u 52.6 ng/mL).
- **Glibenclamide:** generated by
  [tools/build_glibenclamide_ddi.py](tools/build_glibenclamide_ddi.py), sharing
  the same rifampicin model. It adds OATP inhibition (Ki,u 0.226 µM) and CYP2C9
  induction.

### Antibody minimal PBPK

Plasma exchanges with the interstitial fluid of "tight" and "leaky" tissues by
convection through vascular pores, set by the reflection coefficients σ1 and σ2.
Lymph returns the fluid to plasma. The TMDD extension adds target synthesis,
degradation, quasi-steady-state binding and internalisation in both interstitial
spaces. Presets are the published fits:

- trastuzumab with its HER2 parameters (Cao & Jusko 2014, Table 2)
- ten linear antibodies (Cao et al. 2013, Table 2, Model A)

## What the models reproduce

These are checked on every build (`tests/test_published_behaviour.R`,
`tests/test_small_molecule.R`):

- **Midazolam:** after rifampicin 600 mg daily for 7 days, the oral AUC ratio is
  0.095 (clinically about 90–95% lower) and the IV ratio is 0.47. The effect is
  dose-dependent from 5 to 600 mg.
- **Glibenclamide:** a single IV rifampicin dose gives an AUC ratio of 2.12
  (paper's simulation 2.08, observed 2.18). After 7 days of oral rifampicin it is
  0.50 (paper 0.50, observed 0.35).
- **Trastuzumab:** 4 mg/kg then 2 mg/kg weekly gives a week-12 trough of about
  51 µg/mL. Low doses are cleared much faster than high ones (TMDD).
- **Small-molecule model:** mass balance, dose-proportionality, well-stirred
  hepatic clearance, oral F = Fa·Fg·Fh, and the caffeine half-life falling as
  CYP1A2 matures.

## Two engines, one model file

Every model is an mrgsolve model file in [models/](models). mrgsolve compiles C++,
which a browser can't do, so the browser apps use:

- **Small-molecule model:** it is linear, so the browser solves it exactly with a
  matrix exponential ([apps/small-molecule/R/pbpk_engine.R](apps/small-molecule/R/pbpk_engine.R)).
  It agrees with mrgsolve to about 2e-8.
- **All other models:** [shared/ode_engine.R](shared/ode_engine.R) reads the
  same model file, translates it into vectorised R, and integrates it with a stiff
  Rosenbrock solver. It agrees with mrgsolve to within 1e-4 at the tolerances the
  apps use.

Run locally with mrgsolve installed, the apps simulate through mrgsolve instead;
the About tab says which engine is in use. The tests compare the engines on every
build, and nothing deploys if they drift apart.

## Running it locally

```r
install.packages(c("shiny", "shinydashboard", "DT", "ggplot2", "scales"))
install.packages("mrgsolve")   # optional; needs a C++ toolchain (Rtools on Windows)
shiny::runApp("apps/ddi-cyp3a")
```

Tests, from the repository root:

```sh
Rscript tests/test_small_molecule.R              # base R only
Rscript tests/test_published_behaviour.R         # base R only
Rscript tests/test_small_molecule_vs_mrgsolve.R  # needs mrgsolve
Rscript tests/test_models_vs_mrgsolve.R          # needs mrgsolve
```

## Layout

- `models/`: the mrgsolve model files
- `apps/<name>/`: one Shiny app per model
- `shared/`: the model-file engine, rifampicin dosing helpers, app helpers and styling
- `reference/`: the mrgsolve engines used locally and by the tests
- `tools/`: model builders and the app assembly script
- `tests/`: engine agreement and published-behaviour checks
- `landing/`: the index page of the site
- `.github/workflows/shinylive.yml`: tests, WebAssembly export and GitHub Pages deploy
